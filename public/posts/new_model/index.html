Here is the Algorithm for Learning applied to [Python Decorators].

Phase 1: Abstraction (The Magic Box)

Input: Python Decorators.

  • Initialize Big_Picture (The Box):
    • Input: A function (let’s call it function_A).
    • Output: A new function (let’s call it function_B) that does exactly what function_A did, but with some extra stuff happening before or after it runs.
    • The Sentence: A decorator is a tool that allows you to “wrap” extra functionality around an existing function without modifying the code inside that function.
  • Contextualize (Why?):
    • Imagine you have 50 functions in your codebase. You want to log “Start” and “Stop” for every single one.
    • Without the box: You have to open all 50 functions and copy-paste print statements into every single one. If you change your mind, you have to edit all 50 again.
    • With the box: You write the logging logic once (the decorator) and just “tag” the 50 functions. It adheres to the DRY principle (Don’t Repeat Yourself).

Item 2: The Closure (The Wrapper)

Step A: Define the Problem
do_twice above executes the function immediately. That’s bad. We want to return a new function that contains the extra behavior, so we can use it later.

Step B: The Struggle
How do we create a variable that holds “The old function + the new behavior”?
We need to define a function… inside a function?

Step C: Fill the Gap
We define a wrapper function inside the main function.

Python

def my_decorator(original_func):
    # This is the "wrapper" (The Sandwich)
    def wrapper():
        print("Something is happening before the function is called.")
        original_func() # The meat
        print("Something is happening after the function is called.")
    
    return wrapper # Return the wrapper, don't call it yet!

Insight: The wrapper remembers original_func even after my_decorator finishes running. This is a Closure.

Item 3: Syntax Sugar & Arguments

Step A: Define the Problem

  • Writing my_func = my_decorator(my_func) is ugly and repetitive.
  • If original_func takes arguments (like add(a, b)), the simple wrapper() above will crash because it takes 0 arguments.

Step B: The Struggle

  • How do we make the syntax cleaner?
  • How do we make a “universal” wrapper that accepts any number of arguments?

Step C: Fill the Gap

  • Use the @ symbol.
  • Use *args and **kwargs to accept everything and pass it on. Python
def universal_decorator(original_func):
    def wrapper(*args, **kwargs):
        print("Wrapper Start")
        result = original_func(*args, **kwargs) # Pass inputs through
        print("Wrapper End")
        return result # Pass the answer back
    return wrapper

@universal_decorator
def add(a, b):
    return a + b

# This is equivalent to: add = universal_decorator(add)

import functools

def name_of_decorator(func):
    @functools.wraps(func) # Best practice: preserves name/docstring
    def wrapper(*args, **kwargs):
        # 1. Code before
        value = func(*args, **kwargs)
        # 2. Code after
        return value
    return wrapper

def timer(func):

The Concept: Anatomy of the Payload

Before writing the loop, you must intuitively understand what these variables hold:

  • args: This is a Tuple. It holds standard arguments (e.g., (1, 5, “hello”)). You iterate over it like a list.
  • kwargs: This is a Dictionary. It holds named arguments (e.g., {‘age’: 30, ’name’: ‘Alice’}). You iterate over it using .items().

The Implementation

Here is the pattern to inspect (iterate through) every single argument passed to your function.

Example 1: The “Spy” (Logging every input)

This decorator prints every argument received before running the function.

Python

def input_spy(func):
    def wrapper(*args, **kwargs):
        print(f"--- Calling function: {func.__name__} ---")
        
        # 1. Iterate through Positional Arguments (Tuple)
        print("Positional Arguments:")
        for index, arg in enumerate(args):
            print(f"  Arg {index}: {arg} (Type: {type(arg).__name__})")
            
        # 2. Iterate through Keyword Arguments (Dictionary)
        print("Keyword Arguments:")
        for key, value in kwargs.items():
            print(f"  Key '{key}': {value} (Type: {type(value).__name__})")
            
        print("--- End of Inspection ---")
        
        # Finally, pass them to the actual function
        return func(*args, **kwargs)
    return wrapper

# --- Application ---

@input_spy
def create_user(name, age, is_admin=False):
    print(f"User {name} created.")

# Test it with mixed arguments
create_user("Alice", 25, is_admin=True)

Example 2: The “Bouncer” (Validating inputs)

This is a Phase 4 Application test. We will iterate through args to enforce a rule: No negative numbers allowed.

If we find a negative number in args, we raise an error.

Python

def only_positive_numbers(func):
    def wrapper(*args, **kwargs):
        
        # Iterate through positional args to check for negatives
        for arg in args:
            # Check if it's a number (int or float)
            if isinstance(arg, (int, float)):
                if arg < 0:
                    raise ValueError(f"Found negative number: {arg}. Only positives allowed!")
        
        # Iterate through kwargs values
        for key, value in kwargs.items():
            if isinstance(value, (int, float)):
                if value < 0:
                     raise ValueError(f"Found negative number in '{key}': {value}")

        return func(*args, **kwargs)
    return wrapper

@only_positive_numbers
def add(a, b):
    return a + b

A Crucial Insight (The “Gotcha”)

In Python, tuples (args) are immutable. You cannot change them directly.

If you try to do this inside the wrapper:
args[0] = 100 -> Error.

If you need to MODIFY the arguments (e.g., round all numbers):

  • Convert args to a list.
  • Modify the list.
  • Convert it back to a tuple (optional, but good practice) or pass as unfolded list.

Example of Modification:

Python

def shout_args(func):
    def wrapper(*args, **kwargs):
        # 1. Convert tuple to list to make it mutable
        args_list = list(args)
        
        # 2. Modify the list (Capitalize all strings)
        for i, arg in enumerate(args_list):
            if isinstance(arg, str):
                args_list[i] = arg.upper()
        
        # 3. Unpack the MODIFIED list into the function
        # Note: We use *args_list now, not *args
        return func(*args_list, **kwargs)
    return wrapper

@shout_args
def greet(name, message):
    print(f"{name} says: {message}")

greet("john", "hello world") 
# Output: JOHN says: HELLO WORLD
